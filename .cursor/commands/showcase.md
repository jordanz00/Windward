# /showcase

Write or refresh the public-facing showcase for a project.

## Steps

1. Use `TEMPLATES/SHOWCASE_TEMPLATE.md` → `PROJECTS/NNN-TITLE/SHOWCASE.md`.
2. Visitor voice: what it is, how to open it, how it was made — not internal sprint status.
3. Link stills/media when available.
4. Update `PORTFOLIO.md` row and register/showcase links.

## Output

Showcase path + portfolio diff summary.
