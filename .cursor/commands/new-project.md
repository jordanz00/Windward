# /new-project

Create a new studio experiment from the backlog or a founder pitch.

## Steps

1. Read `STUDIO.md`, `OPERATIONS/PROJECT_REGISTER.md`, `OPERATIONS/IDEAS_BACKLOG.md`.
2. Allocate the next ID (`NNN`) and slug `PROJECTS/NNN-TITLE/`.
3. Copy `TEMPLATES/PROJECT_BRIEF.md` → `PROJECTS/NNN-TITLE/PROJECT_BRIEF.md` (fill concept, vision, v1 scope).
4. Add rows to `PROJECT_REGISTER.md` and `ACTIVE_PROJECTS.md`; trim backlog if promoting an idea.
5. Do **not** start coding the experiment until `/plan` is approved.

## Output

Paths created + brief summary for founder approval of the brief.
