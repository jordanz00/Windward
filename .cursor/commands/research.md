# /research

Research for the active (or named) project. No app rewrites.

## Steps

1. Confirm project folder under `PROJECTS/`.
2. Gather constraints, references, technical risks, prior art — write into the project folder (e.g. `RESEARCH.md`) or append to the brief.
3. Call out what would make a **bounded achievable v1**.
4. Do not edit production app source unless this research was scoped as read-only on that code (Windward: read `source/` / README / notes; do not rewrite).

## Output

Research notes + open questions for `/plan`.
