# /review

Review the project against its brief.

## Steps

1. Read brief, plan, and what actually shipped.
2. Fill `TEMPLATES/PROJECT_REVIEW.md` into the project folder.
3. Distill reusable lessons into `OPERATIONS/LESSONS_LEARNED.md`.
4. Update ACTIVE / COMPLETED / REGISTER as appropriate.
5. Do not claim verification that was not run.

## Output

Review path + verdict (Met / Partial / Missed).
