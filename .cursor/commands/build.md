# /build

Implement only against an **approved** plan or bounded approved task list.

## Steps

1. Confirm approval (plan status Approved, or founder message approving tasks).
2. Implement the listed tasks only; no scope expansion without a plan update + re-approval.
3. Run the project’s verification (for Windward engineering: build + load/WebGPU gates as required).
4. Update task checkboxes / ACTIVE_PROJECTS; label anything unverified.

## Stop and ask if

Destructive change, architecture rewrite, publish, secrets, or license/distribution work appears necessary.
