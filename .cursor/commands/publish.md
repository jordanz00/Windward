# /publish

Deploy or mirror **only after explicit founder approval**.

## Steps

1. Confirm the founder asked to publish (this command alone is not approval if the chat did not say so).
2. State exactly what will go live (branch, host, Pages, mirrors).
3. For Windward: Origin push vs GitHub Pages mirror — prefer docs-safe mirrors when only studio markdown changed; never break live `index.html` with unrelated churn.
4. Verify the live URL after publish; record result in OPERATIONS or an internal note if used.
5. If approval is missing: stop and ask.

## Output

URLs + SHAs verified, or a clear blocked-on-approval message.
