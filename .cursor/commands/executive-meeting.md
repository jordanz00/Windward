# /executive-meeting

Run the weekly executive leadership meeting (simulated async).

## Steps

1. CEO opens with objectives and constraints from `company/STRATEGY.md`.
2. Each SVP domain contributes status: accomplishments, problems, decisions required, next objectives — **no fabricated KPIs**.
3. Reconcile conflicts; escalate Level-4 items.
4. Write a dated note under `company/reports/` or summarize in-chat if the founder prefers no file write.
5. Update `company/executives/decisions-log.md` only for real decisions made in-session.
