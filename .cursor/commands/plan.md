# /plan

Produce an achievable development plan and **stop for founder approval** before build.

## Steps

1. Read the project brief + research.
2. Copy `TEMPLATES/DEVELOPMENT_PLAN.md` into the project folder; fill v1, tasks, acceptance, verification, risks.
3. Update `OPERATIONS/ACTIVE_PROJECTS.md` stage to Plan.
4. Explicitly list what needs founder approval.
5. Do **not** run `/build` or change app source until approved.

## Output

Plan path + short “approve to build?” ask.
